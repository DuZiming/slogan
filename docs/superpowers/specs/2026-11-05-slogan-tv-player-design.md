# Slogan — 电视盒子/智能电视本地视频播放器 设计文档

日期：2026-11-05
状态：**已定稿**（产品负责人 2026-11-05 确认）
产品名：**Slogan**
广告语：**影聚于此，一屏尽收**

---

## 1. 一句话定位

面向国内安卓电视/盒子的**本地 + NAS 高品质视频播放器**：Netflix 级的电视墙 UI + 硬核播放素质（音频直通等），¥30 买断制，**纯离线产品（不发起任何互联网连接，仅局域网访问 NAS）**，零服务端。

## 2. 为什么做（意图）

- 现有收费播放器（Kodi 等）UI 不够美观；盒子/电视自带播放器只是"资源管理器 + 全屏播放"，没有体验。
- 国内电视应用市场没有"付费下载/内购代收"机制，竞品无法靠市场变现，用户体验停滞。
- Slogan 填的空档：**颜值在线（Netflix 质感）+ 播放素质硬（直通/原盘）+ 付费干脆（买断）**，三者同时成立的纯本地方案。
- 对标免费竞品"当贝播放器"（有海报匹配但 UI 平庸、无音频直通）——它是必须明显超越的对象。

## 3. 用户与场景

- 国内用户，安卓智能电视（小米/TCL/海信等）+ 安卓电视盒子（当贝、腾讯极光及各类魔百盒）。
- 片源：U盘/移动硬盘/电视本地存储 + 家用 NAS（SMB 为主，NFS 进阶），4K MKV/REMUX/蓝光原盘为主，追求画质音质。
- 典型场景：晚上打开电视 → 海报墙找到没看完的片子 → 一键继续播放，杜比/DTS 直通到功放。

## 4. 目标 / 非目标 / 反目标

**目标**
1. Netflix 级 TV UI：纯黑底、焦点动效、横向内容行、沉浸 Hero。
2. 全格式本地播放：视频容器/编码通吃，音频直通（能力探测 + 无缝回退）。
3. 纯本地媒体库海报墙：封面链 + 智能截帧 + 文件名清洗 + 剧集归组 + 画质探测，零互联网。
4. 在小米电视 A55（四核 A35、约 2GB RAM）上流畅运行——**这是合格线**。
5. ¥30 买断：免费完整基础体验 + 专业功能解锁，卡密离线验证，零服务端。

**非目标（v1 明确不做）**
- 网盘/在线视频播放、内容聚合、直播源。
- 多用户 Profile（v2）。
- 自建服务端（激活验证、云同步、推荐服务）。
- WebDAV / DLNA / FTP 等更多协议（v2+）。
- 复杂多条件筛选（TV 端刻意弱化，按 Netflix 逻辑）。

**反目标（做了就算失败）**
- 广告、订阅制套路、"下载即收费"。
- UI 卡顿、焦点丢失、遥控器操作反直觉。
- 任何对互联网的依赖（唯一的网络行为是局域网 SMB/NFS 访问 NAS；无遥测、无云、无在线资料）。
- 用户数据上传（应用不发起任何互联网连接）。

## 5. 产品决策

### 5.1 品牌与视觉基调

- 纯黑 `#000` 底（降低电视眩光），主色 **Netflix 同款红 `#E50914`**（播放/主操作按钮），白主文字、浅灰辅助文字。
- 文字层级：大标题粗白、标签小字浅灰、简介浅灰细字；电视端大字号、宽行距。
- 遮罩：文字区用上→下渐变暗遮罩，保留背景图氛围。
- 动画：缓动低速、不频闪、无硬切；焦点第一优先级。

### 5.2 交互规格（Netflix TV 交互逻辑）

- 遥控器：方向键移动焦点；**焦点是第一优先级**。选中卡片：放大、上浮、柔和外发光；相邻卡片轻微缩小避让；行滚动带阻尼。
- **长按 OK = 菜单**（国产遥控器无独立菜单键，此为全局习惯）。
- 返回键语义：播放页 → 详情页 → 上级页面，不直接跳首页。
- 导航（常驻顶部、低透明度、窄条）：Logo → 搜索 → 首页/电影/剧集/收藏/文件 → 设置；选中 Tab 白色高亮 + 红色细下划线。

### 5.3 页面结构

**首页**：顶部导航 + Hero 大图（优先放"未看完/最近添加"，背景为处理过的本地截帧，叠加影片大标题、画质标、年份时长、红色【播放】第一焦点 +【更多信息】+ 简短信息行）+ 无限横向行（继续观看[红进度条] / 最近添加 / 未看完 / 收藏 / 4K / 杜比全景声 / 看得最多），行尾「›」进列表页。

**分类页（电影/剧集）**：无 Hero；顶部子分类条（全部 / 4K / HDR / 杜比 / 新添加——全部来自本地文件探测）；统一 Tile 卡片；无复杂筛选。

**搜索页**：虚拟键盘（遥控器操作）+ 实时联想（搜本地库：片名/文件名/文件夹路径）。

**详情页**：顶部大背景（处理过的截帧，可自动播预览）+ 影片大标题 + 标签行（年份/画质标/文件规格）+ **技术参数面板**（分辨率/编码/码率/音轨列表/字幕轨/文件大小——发烧友向）+ 红色【播放/继续观看】第一焦点 +【收藏】+【已看/不感兴趣】+ 剧集分季选集（集卡：截帧缩略图/标题/时长/进度红条）+「同文件夹 / 同系列」行。

**播放页**：全屏无控件，任意键唤出、数秒无操作自动隐藏。顶栏：片名/集数、字幕/音频设置、退出。底栏：-10s / 播放暂停 / +10s、细进度条（红进度点 + 缓冲段）、当前时间/总时长。片尾自动倒计时下一集。返回键回详情页。

**文件页**：刮不出的内容与私人视频在此（经典文件浏览器，SMB/NFS/本地统一），不污染海报墙。

**弹窗**：居中小块、小圆角、红主钮 + 灰取消。

**设置**：媒体源管理（SMB/NFS/本地路径）、音频直通（自动探测结果可见、可手动锁）、字幕（大小/颜色/背景）、预览开关、解锁管理。

### 5.4 媒体库构建（纯本地，零互联网）

- **封面链**（按优先级取第一个可用）：① 文件夹自带 poster.jpg / cover.jpg / folder.jpg；② MKV 内嵌封面附件；③ **智能截帧**——取片长 15% 处画面（限 3–20 分钟），自动避开黑帧/纯色帧，加电影感处理（暗角 + 渐变）。
- **片名清洗**：从文件名剥离发行标签，`Dune.Part.Two.2024.2160p.WEB-DL.mkv` → `Dune Part Two · 2024`；中文文件名原样保留。
- **剧集归组**：从文件名解析 `S01E05` / `E05` / `第X季` 等模式，按"剧 → 季 → 集"三级归组；每集用截帧做缩略图。
- **画质/规格探测**：读取文件头（FFprobe 系），分辨率 / HDR10+ / 杜比视界 / TrueHD / Atmos / 码率 / 音轨数 / 字幕轨全部本地探测——首页行、分类页子分类、详情页参数面板的数据源。
- **蓝光原盘**（BDMV 文件夹）识别为单影片。
- **私人视频**（婚礼录像等，无影片特征的）：自动归入文件页，不污染海报墙。
- 架构保留**资料源适配层**（纯代码留位，零成本）：将来若加在线刮削（TMDB 等），是一个版本的事，不影响已发版。
- 扫描在可取消的后台服务中执行，结果存本机 SQLite；媒体库完全离线可用、即扫即用。

### 5.5 智能预览（选中卡片的自动视频预览，v1 必须）

按优先级取第一个可用项，播放 **5–8 秒、静音**，焦点移出立即停止：
1. 未看完 → 从**上次进度**播起（最像 Netflix 的续看感）。
2. 有章节（原盘/REMUX）→ 从**中段章节**开场。
3. 兜底 → 从**片长 15%** 处（限制在 3–20 分钟），避开片头厂标/黑屏。
4. 本地 `-trailer.*` 文件优先于以上。
5. 设置项：预览总开关。（原"YouTube 官方预告片源"从 v1 移除——国内不可达且有条款风险；本地 trailer 文件机制保留，在线预告留作 v2 可选项。）

### 5.6 播放核心与音频直通

- C/C++ 内核（mpv/FFmpeg 系）为主引擎：格式通吃、libass 专业字幕、滤镜/音轨处理扩展性（为后续专业功能留路）。
- **音频直通策略**：启动时探测设备 HDMI 输出能力（AC3/DTS/TrueHD/Atmos…），**能通则通，不能通无缝回退高质量软解 PCM 输出**；设置页可见探测结果、可手动锁定，防设备误报。
- 字幕：内封（ASS/SSA/SUP/PGS）+ 外挂（srt/ass，同名字幕自动加载）。
- 续播：所有媒体记录进度（含 NAS 路径），继续观看行贯穿全 UI。
- 技术储备（不承诺 v1）：杜比视界 Profile 处理按设备能力尽力而为。

### 5.7 商业化（已定案）

- **单 APK**：应用市场免费上架（当贝、ZNDS 系、沙发管家等，一次提交同步多商店）。
- **免费功能**（口碑基本盘）：完整海报墙（本地媒体库构建）、SMB/NFS、播放、进度、收藏、智能预览。
- **¥30 解锁专业版**：音频直通、蓝光原盘菜单、预览增强（更长时长/更高码率）及后续全部专业功能；音频直通与原盘菜单各 **3 次免费体验**后提示解锁。**智能预览的基础形态免费**（它是首页质感的口碑基本盘，不锁）。
- **卡密机制（零服务端）**：非对称签名——私钥本地批量生成激活码，APK 内置公钥，**完全离线验证**；销售交发卡平台（面包多/爱发卡类，费率 1–2%，自动发货）；应用内购买页引导扫码 → 发卡平台付款 → 输码解锁。
- **卡密边界（已拍板）**：一码不限设备数（按"一家人一个码"语义销售）；设置页可查看/导出激活码（换机自救）；3 次体验计数存本机，清数据可重置——接受，不做对抗。
- 防破解定位：离线应用无绝对防护；低价买断 + 付款便利即策略，不为此增加架构复杂度。
- 预留：Google Play 国际版（真内购）作为后续增量渠道，架构留开关。

### 5.8 Netflix 元素 → 本地等价替换（速查）

| 服务器推荐行算法 | 本地播放记录 + 文件探测生成的行 |

## 6. 技术方案

| 层 | 选型 | 理由 |
|---|---|---|
| 语言/应用 | **Kotlin** | 安卓官方语言，性能好，维护者好找 |
| UI | **Jetpack Compose for TV** | 焦点动效、卡片动画效率最高，TV 一等公民 |
| 播放内核 | **C/C++ mpv/FFmpeg 内核（JNI 接入）** | 格式通吃、音频直通、libass 字幕、专业功能扩展性 |
| SMB | JVM 成熟 SMB 客户端库（如 smbj/jcifs-ng 系），**v1 支持 SMB2/2.1/3，不支持 SMB1**（连接失败时明确提示） | 纯 Java 无需挂载；SMB1 场景小众且老化 |
| NFS | libnfs（C 库 JNI 封装） | NFS 生态唯一可靠路线（Kodi 同款） |
| 刮削→媒体探测 | FFprobe 系元数据读取 + 本地截帧（FFmpeg） | 分辨率/HDR/音轨/字幕轨全本地探测，零互联网 |
| 图片 | Coil（低内存管线） | 海报加载省内存 |
| 许可 | 离线签名卡密（Ed25519 级别非对称签名） | 零服务端 |

**架构要点**：UI 层与播放引擎解耦（引擎抽象接口），为"默认引擎 + 备用引擎"和未来扩展留位；媒体库为本地 SQLite；媒体源扫描（SMB/NFS/本地）在可取消的后台服务中执行。

**性能预算（以 A55 为准绳）**：
- 冷启动 ≤ 3s 进入首页（有缓存库时 ≤ 1.5s）；海报滚动不掉帧（A55 实测）；预览起播 ≤ 1.5s；空闲内存占用 ≤ 300MB。
- 手段：1080p 渲染 UI + 4K 视频输出、海报按需解码并缓存、列表卡片复用、动画预算克制、预览限码率。

**适配范围**：minSdk = **Android 6.0（API 23）**，明确放弃安卓 4.4/5.x 运营商魔百盒（产品负责人已确认，宣传口径写明"安卓 6.0+"）；arm64-v8a + armeabi-v7a。

**验收环境（已确认到位）**：小米电视 A55（基准机）+ 支持 杜比/DTS 的功放（AVR）+ 现成 NAS（SMB）。无发布时间压力，质量优先。

**上架合规（个人主体路线，已确认不注册公司）**：个人 App 备案 + 个人名义软著 + 个人开发者账号 + 发卡平台个人店铺；办理周期数周至数月，**与开发并行启动**，做大后再升级个体户/公司。

## 7. v1 范围

**包含**：首页/分类/搜索/详情/播放/文件/设置全部页面；SMB + NFS + 本地存储；**本地媒体库构建**（封面链/文件名清洗/剧集归组/画质探测，见 5.4）；剧集分季选集；续播进度；收藏/已看/不感兴趣；智能预览（5.5 全策略）；音频直通（探测+回退+手动锁）；字幕全档；卡密解锁系统；继续观看/最近添加/4K/杜比行。

**不包含**：**TMDB/任何在线资料刮削与互联网功能**（产品负责人定案：纯离线；架构留资料源适配层，v2+ 再议）、多用户、WebDAV/DLNA、**在线字幕下载**（外挂字幕体验做足：自动加载同名 srt/ass、详情页引导；在线字幕源 v2 评估）、原盘蓝光导航菜单（直通的原盘**播放**v1 有，**菜单**视内核进度决定，默认后置——具体由实施计划评估）、Google Play 版、TV 端复杂筛选。

## 8. 后续路线（v2+ 候选，不承诺）

**在线刮削**（TMDB 等资料源，走"官方海报/中文名/简介"增强，架构已留适配层，需重新讨论联网与中转方案）；多用户 Profile；WebDAV/DLNA；Google Play 国际版；蓝光原盘导航菜单；画质滤镜/调色等专业功能；NFO/Jellyfin 库兼容导入。

## 10. 对话中产品负责人的原话要点（存档）

- "现在有这些功能的软件需要收费，且 UI 不够美观；盒子自带播放器只是资源管理器。"
- "我不做网盘播放，专注本地视频播放，可以做音频直通等高质量场景，买断制 30 元。"
- UI 标杆："Apple TV 上 Netflix 和 Disney+ 的首页质感"，后细化为完整 Netflix TV 交互规格（已并入 5.1–5.3）。
- 性能底线设备："小米电视 A55，四核 A35。"
- 商业："卖 30 走量，离线播放器不弄服务端，卡密方式。"
- 评审问答补充定案（2026-11-05）：预览免费、在线字幕 v1 不做、放弃安卓 4.4/5.x 魔百盒、验收硬件齐备（A55+AVR+NAS）、无时间压力、个人主体上架不注册公司。
- **纯离线定案（2026-11-05，产品负责人原话："对，按不连互联网的来做"）**：v1 不做任何互联网功能（含 TMDB 刮削、镜像、中转）；海报墙由本地封面链 + 智能截帧 + 文件探测支撑；在线刮削留待 v2+。
